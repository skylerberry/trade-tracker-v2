R-target ladder — independent design take

Built from the wireframe freeroll contract only (plan presets + action sentence + 1R–5R copy line; trim modal R keys). No reference to other ladder mockups in this repo.

Thesis

  • Two jobs, two surfaces. Calculator ladder = read + copy for chart alerts. Trim modal R keys = write (set price + freeroll share size). Don’t force one control to do both.
  • The freeroll knot is the hero, not every rung. Spec already gives the action sentence. The ladder only needs to make the plan R obvious and the other prices scannable.
  • Click never mutates calculator inputs. Copy only. Visual feedback = toast, not a selected field state that looks like a form value.
  • Density over drama. Market-hours UI. Equal-weight rungs beat proportional “price geometry” that shifts every trade.
  • Shorts: same layout, descending prices, cover language lives in the sentence — ladder stays R-labeled, not direction-labeled.

D · Companion (required)

Trim modal · R keys

Different component, same R math. These write exit price. With Risk Manager on, each key also shows the freeroll share count. Drop 4R here — wireframe omits it for a clean 4-up grid.

Trim / Exit modal excerpt

Risk Manager on · ½ / ⅓ / ¼ / ⅙ freeroll sizes (rounded up to whole shares)

Do not reuse the calculator rail here. Modal keys need pressed state + share outcome on the face of the button. Calculator rungs must stay non-selecting.

Ship recommendation

Calculator: A · Rung rail. Sentence stays the narrative; rail is the alert clipboard. Plan rung only uses success green (same family as freeroll shield). Everything else is gray steps.

Trim/Exit: keep a dedicated R-key grid (D). Optional micro-upgrade: show freeroll share count under each key when Risk Manager is on — turns “pick a price” into “pick a freeroll size” without an extra sentence.

States to wire when implementing A:

  1. half-1r / third-2r — mark that R with shield + hint (sell ½ / sell ⅓)
  2. backfill — mark 1R with hint stop → BE, no sell fraction
  3. off — no plan mark; all five rungs equal quiet
  4. option mode — same rail, title already “Underlying R map”; no sell hints
  5. short — descending prices; hints still “cover ½” language if you want direction-aware copy
  6. invalid calc — hide rail or show em-dashes; never invent R prices
