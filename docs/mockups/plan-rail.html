1 The metadata now has a container

The old · stop 9.50 · risk / share $0.50 was 11px gray text tucked behind a date — the two numbers that define the trade, styled like a footnote.

Now it's a bordered 4-up spec block under each event: 9px uppercase label above a 14px value. Same footprint, but the numbers read as data instead of prose. Risk numbers go red, captured numbers go green, so the eye lands before the brain does.

2 The dead space is actually bottom-left

The right column is already carrying stats plus the journal. The ~1000×500 void in your screenshot sits under the Trim/Exit buttons.

So the plan rail goes full-width below both columns rather than into the right column. It needs the width — a 5R price axis squeezed into 40% would be unreadable — and it keeps the journal where the muscle memory already is.

3 The rail is a decay curve, not a timeline

X is price (dual-labeled in dollars and R). Y is shares still on. The staircase says the whole story in one glance: 140 rode to 11.00, 93 are live now, 47 run open-ended.

Solid = traveled, tinted = the live leg, hatched-dashed = plan. The struck-through 9.50 and the green arrow to breakeven are what earns the FREEROLLED pill in the header — right now that pill asks you to take its word for it.

4 It doubles as the planning surface

Every node is a hit target. Drag a planned node along the axis to reprice it, click to set share count. + Add target drops a new step. Filled nodes lock.

That turns the card from a record into a plan you maintain — which is the same argument the journal is making one column over.

Collapsed row — same rail, 40px tall

If the rail only lives in the expanded card you lose it when scanning a list. This strip is the same data compressed to one line, so a 20-position table still shows where every trade sits in its plan.
